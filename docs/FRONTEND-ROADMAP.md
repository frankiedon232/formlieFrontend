# Frontend Roadmap — formalieFrontend

**Every task, its status and the progress log now live in [PROGRESS.md](../PROGRESS.md)** (repo root). This file only keeps the phase order and the rules for working through it.

## Phase order

F0 Foundation → F1 App shell → F2 Core plumbing → F3 Workspace detection + sign-in → F4 Onboarding → F5 Forms list and lifecycle → F6 Builder → F7 Designer → F8 Renderer, share, embed, SEO → F9 Responses → F10 Templates → F11 Settings, option sets, integrations → F12 Profile → F13 Users → F14 Analytics → F15 Live collaboration (optional) → F16 Roles & access, audit trail, dashboard (last).

## How we work through it

1. One phase at a time, in order; stop for the owner's review at the end of each phase.
2. A phase is done only when it passes the checklist at the top of PROGRESS.md (devices, keyboard, light / dark, Arabic RTL, states, 20 languages, design match, checks green, docs updated, pushed).
3. New work is added to the right phase in PROGRESS.md **and** to its New requests log as soon as it comes up.
4. After every verified milestone: tick the task, add a Progress log line, update the overview table and "Last updated", commit and push.

Earlier detailed notes (2026-10-02 and before) are in git history: `git log -p docs/FRONTEND-ROADMAP.md`.
